# Read, After
Mode: Experience. A cinematic desktop of two unequal floating windows; the read receipt stays still as the hidden scene changes. The floating windows borrow the spatial metaphor discussed with the user, while scene rhythm and glimpses of elsewhere inform the reveal. No copied reference artwork or code.
